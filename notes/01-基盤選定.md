# 基盤選定メモ (2026-10-16)

## 目標
聴いて生まれる感性 → 理論で調整 → 感情を理論的に表現する、というループを支える DTM。
Linux(WSL/bash) と Mac で動く GUI アプリ。

## 段階
1. OSS の DTM を土台にし、MCP サーバーを作る。クライアントは Claude Code
2. 音符・任意の枠・トラックなど各粒度にコメントを付けて調整できる専用 MCP クライアント(UI)
3. 音源も作れる DTM として発展させる(デスクトップ配布は Tauri/Electron で包む)

## 候補比較
| 候補 | ライセンス | 長所 | 短所 |
|---|---|---|---|
| ryohey/signal | MIT (GitHub API で確認) | TypeScript のブラウザ MIDI エディタ。ピアノロール、SoundFont、WAV 書き出し、Web MIDI 入力。2026-10 時点でも更新あり。Linux/Mac はブラウザで同一に動く | DAW としての機能(ミキサー、プラグイン)は薄い |
| Ardour | GPL | 本格的な DAW | MCP は OSC 経由(ardour-mcp)で、ノート単位の編集は弱い。C++ で改造が重い |
| 既存 MCP (music21 系, daw-midi-generator 等) | 各自要確認 | 理論解析や MIDI 生成にそのまま使える | ノート単位の双方向編集や UI はない |

## 暫定結論
Signal を fork して土台にする。ノート・トラック・イベントのドキュメントモデルが TypeScript で手に入り、
段階2のコメント UI も同じコードベースに載せられる。理論解析は music21 などを別プロセスで併用する。
